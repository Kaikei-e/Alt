# Alt セキュリティ是正 運用・監査・クリーンアップ記録 (2026-10-02)

本ドキュメントは、セキュリティ是正に伴うアーティファクト管理、オフラインクリーンアップ、保持資産、およびコミット準備運用の事実を簡潔かつ正確に記録する。全53件の是正判定・技術詳細は主台帳 [20261002-security-remediation.md](20261002-security-remediation.md) に集約されている。

## 1. Pactアーティファクトの経緯と是正

- **未承認ダウンロード**: 既存CIにPact検証の仕組みが存在していた事実はあるが（免責理由にはならない）、明示的な事前承認を得ずにPact CLI (12,700,060 B) および FFI (6,901,629 B) のアーティファクトがダウンロード・展開されていた。
- **実行履歴の扱い**: 保存ログだけでは全期間のCLI実行有無を確認できていない。「一度も実行されていない」とは主張せず、全期間の実行有無は「未確認」として記録する。
- **承認に基づく削除**: ユーザーからの明示的なクリーンアップ承認を受け、オフライン `sol_infra_review` にて3,354アイテム（2,819ファイル、535ディレクトリ、未知ファイル0、シンボリックリンクなし）がCLIアーカイブとバイト完全一致することを確認した。ルート直下の `pact/` および `pact_download/` を正確に削除し（Exit 0）、ネイティブファイルシステム上で存在しないこと（ABSENT）を確認済。クリーンアップ中のダウンロードやPact実行は一切行われていない。

## 2. Cargoビルドキャッシュのオフラインクリーンアップ

ユーザーからの明示的な指示に基づき、Rust 3サービスのビルドキャッシュをオフラインで削除（Exit 0）：
- **rask-log-forwarder**: 15,079ファイル, 約10.4 GiB
- **rask-log-aggregator**: 8,718ファイル, 約5.9 GiB
- **recap-worker**: 81,168ファイル, 約44.6 GiB
- **合計**: 104,965エントリ, 約60.9 GiB（※概算丸め表示であり、厳密な実測ディスク回収量ではない）。

各サービスの `target/` ディレクトリが存在しないことを確認済。クリーンアップ作業中の新規ダウンロードやビルド実行は発生していない。

## 3. 出所不明バイナリ・保留スクラッチの保持方針

以下の出所不明バイナリおよび修正スクリプトは、隠蔽や無断削除を行わず、現状のまま保持（KEEP）している：
- `auth-hub/auth-hub`
- `alt-backend/app/backend`
- `rag-orchestrator/server`
- リポジトリルートに存在する出所不明な修正スクリプト群

過去に削除が拒絶されたスクラッチファイル類も保持を継続している。これらバイナリの過去全期間における正確な実行履歴は「不明 (unknown)」として管理する。

## 4. ランタイム・データベース検証境界の限定

- **実機検証の除外**: 本タスクにおいて、実機コンテナ負荷試験、Docker起動、実データベースDELETE処理、本番デプロイは一切実施していない。
- **ゴミクリーンアップ未完了**: 全クロスストア（Meili/Redis/detached rows）の歴史的ゴミデータ完全クリーンアップは未検証（UNVERIFIED）。
- **SQLスナップショット**: 読取専用スコープにおいて4ブロックのSQL countがゼロであることを確認した範囲に限定される。

## 5. 分割コミット準備と今後の運用原則

- **分割コミットの隔離準備**: `/tmp` 上の隔離されたworktreeにて新規セキュリティブランチを準備。元のGo 1.27作業ツリーおよびステージ状態は設計通り意図的に保持している（コミットは保留中であり、架空のコミットSHAは捏造しない）。
- **今後の運用原則**:
  1. **外部ツール・依存関係**: 外部バイナリ・依存関係のダウンロードやインストールは、ユーザーの明示的許可なしに実行してはならない。
  2. **テスト実行**: テストはローカルキャッシュ・オフライン環境のみで実行する。
  3. **Cargoクリーン**: `cargo clean` は意味のあるRust検証完了後かつハンドオフ前に、ユーザーの明示的要請に基づいて実行する。他者のソースやキャッシュを無断で自動削除してはならない。
